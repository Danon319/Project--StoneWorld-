ПРАВКИ К БРИФУ Hero (SEC-1). Применить к уже собранной секции.
Отменяют все предыдущие патчи целиком. Остальные значения брифа в силе.

1. СЛОГАН УДАЛЯЕТСЯ, НА ЕГО МЕСТО ВСТАЁТ РАЗДЕЛИТЕЛЬНАЯ ЛИНИЯ
   Класс sw-hero__slogan и его стили снимаются полностью.
   Вместо него sw-hero__divider: декоративный пустой div (не hr, не img),
   первый элемент внутри sw-hero__content, до h1.
   - высота 1px
   - фон var(--sw-color-link-hover, #A68A73)
   - ширина clamp(346px, 0.78125vw + 340px, 360px)   опорные 360px / 346px
   - margin-inline: auto
   - в дереве доступности не участвует, aria не задаётся, текста нет
   Первым текстовым элементом панели становится h1.

2. ВЫСОТНАЯ СИСТЕМА РАЗМЕРОВ СНИМАЕТСЯ ЦЕЛИКОМ
   Все «высотные пределы» в svh и конструкция min(ширинный clamp, высотный
   предел) удаляются — для H1, подзаголовка, высоты и кегля кнопки.
   Остаются только ширинные clamp(). Раздел «Сжатие по высоте» из АДАПТИВА
   снимается, опорные 100svh = 1345px / 986px не используются.
   Нижний порог кнопки max(44px, …) снимается: минимум ширинного клампа
   выше 44px, порог не срабатывает.
   Причина: опорные высоты вьюпорта были расчётными, а не замеренными,
   на реальном устройстве система разъезжается.

3. ВЫСОТА СЕКЦИИ
   height: 100svh  →  min-height: 100svh
   Фолбэк строкой выше: min-height: 100vh
   Причина: при нехватке высоты (телефон в альбомной ориентации) секция
   вытягивается вместо обрезки контента.
   Равенство частей по высоте в строчной раскладке — align-items: stretch.

4. КЕГЛЬ H1 — новая опорная величина на ≤768: 38px (было 66px)
   clamp(38px, 2.2321vw + 20.86px, 78px)
   На 2560 прежние 78px. line-height остаётся calc(1em + 8px).
   max-width заголовка не меняется: clamp(615px, 13.1138vw + 514.29px, 850px).

5. ПОДЗАГОЛОВОК — новая опорная величина на ≤768: 17px (было 23px)
   кегль      clamp(17px, 0.558vw + 12.71px, 27px)       опорные 27px / 17px
   max-width  clamp(357px, 13.5603vw + 252.86px, 600px)  опорные 600px / 357px
   line-height остаётся calc(1em + 8px), margin-inline: auto.

6. КНОПКА — новые опорные величины на ≤768
   высота  clamp(57px, 3.5156vw + 30px, 120px)      опорные 120px / 57px
   кегль   clamp(18px, 0.6138vw + 13.29px, 29px)    опорные 29px / 18px
   радиус  24px при min-width: 769px
           12px при max-width: 768px
           ступенькой, между значениями не интерполируется
   позиция на ≤768: три зазора от краёв видео-блока равны — 39px слева,
   справа и снизу (было 44px снизу)
   фоны, цвет текста, hover, active, точка ≤425 — без изменений

7. ВЕРТИКАЛЬНЫЙ РИТМ ПАНЕЛИ — новая схема
   Все отступы фиксированные, кроме одного растягивающегося на каждом
   состоянии. Панель выше контента, лишнюю высоту забирает растягивающийся.

   ≥769:
     верх панели → линия        clamp(35px, 3.3482vw + 9.29px, 95px)
     линия → заголовок          clamp(70px, 9.4866vw - 2.86px, 240px)
     заголовок → подзаголовок   clamp(15px, 13.1138vw - 85.72px, 250px)
     подзаголовок → кнопка      РАСТЯГИВАЮЩИЙСЯ, flex-grow: 1,
                                min-height: clamp(50px, ...) с опорным 50px @2560
     кнопка → низ панели        clamp(85px, 0.558vw + 80.71px, 95px)

   ≤768:
     верх панели → линия        35px
     линия → заголовок          70px
     заголовок → подзаголовок   15px
     подзаголовок → низ панели  РАСТЯГИВАЮЩИЙСЯ, flex-grow: 1,
                                min-height: 85px

   Итог: на ≥769 кнопка прижата к нижнему краю панели, свободное поле
   собирается между подзаголовком и кнопкой. На ≤768 кнопки в панели нет,
   текст стоит группой сверху, свободное поле собирается под ним.

   Классы: sw-hero__spacer--slogan удаляется.
   sw-hero__spacer--title и sw-hero__spacer--subtitle — фиксированные отступы.
   sw-hero__spacer--bottom — на ≥769 фиксированный, на ≤768 растягивающийся.
   Растягивающийся на ≥769 — sw-hero__spacer--cta (новый класс на месте
   отступа «подзаголовок → кнопка»); на ≤768 не применяется.

8. ТАБЛИЦА ОТНОСИТЕЛЬНЫХ РАЗМЕРОВ ТЕКСТА в разделе СЕТКА снимается:
   после правок отношения различаются между состояниями. Таблица справочная,
   на код не влияет.
