Шаг 10 роадмапа. Собираем ОДНУ секцию в цехе `/root/index.html`.

- Требования заказчика не додумывать: прямой связи с заказчиком нет.

  попадёт в код.
- Чужие секции и зоны не трогать. `:root` в ЗОНЕ A пополнять только с явного разрешения.

  `/* стиль — секция X */`, `/* поведение — секция X */`, `<!-- разметка — секция X -->`.

## 5. Жёсткие правила кода

CSS
- БЭМ с префиксом секции. Классы с `t-` и `tn-` запрещены, включая генерируемые SplitText.
- Все стили обёрнуты в контейнерный селектор секции и за него не утекают.
- `box-sizing` — первой строкой стилей, посекционно, через потомковый `*` внутри контейнера.
- Глобальных селекторов нет: `body`, `*` в корне таблицы, голые `a`, `h1`–`h6`, `p`, `ul`.
- Сброса стилей нет. Каждый элемент задаёт свои `margin`, `padding`, `list-style`,
  `text-decoration` явно, через свой класс `sw-*`.
- `var()` всегда со вторым аргументом. В `@media` — литеральные px.
- Своего `@font-face` нет. Шрифт — через `var(--sw-font-family, …)`.

JS
- IIFE. Глобальных переменных нет.
- Секция проверяет наличие своих DOM-узлов и тихо ничего не делает, если их нет.
- Перед использованием библиотеки — проверка (`if (!window.gsap) return;`,
  отдельно `window.SplitText`).
- `gsap.registerPlugin` в секции не вызывается — он один раз в блоке инициализации.
- Секция не зависит от порядка выполнения соседей и переживает перемещение в редакторе.
- jQuery и PHP не использовать.

Разметка
- Ассеты — только абсолютные URL из брифа. Нет URL — стоп, вопрос. Пути цеха запрещены.
- `alt` заполнен везде. `loading="lazy"` везде, кроме первого экрана.
- Иконки не рисовать, включая SVG-заглушки и плейсхолдеры. Источник — `/Design_system/Icons`
  и абсолютные URL из брифа. Нужной нет — описать словами, остановиться, ждать.
- H1 ровно одна на всю страницу и живёт в Hero. H2 — заголовок секции, H3 — внутри,
  уровни не пропускаются. Заголовки — настоящие теги с классами `sw-*`.
  Слоган «Искусство вне времени» — не заголовочный тег вообще.

Границы и анимации
- Граница перестроения — 768px включительно. Компактное состояние `max-width: 768px`,
  десктопное `min-width: 769px`. Вариантов с `767` в проекте нет: если `767` встретится
  в design_system.md 2.7 или CLAUDE.md — это устаревшая формулировка, применять 768/769.
  То же в `gsap.matchMedia()`.
- Hover-эффекты — под `(hover: hover)` и `(min-width: 769px)`.
  `:active` под `(hover: hover)` НЕ прятать там, где смена состояния несёт смысл.
  На iOS Safari `:active` не срабатывает без слушателя касания на самом элементе.
- `prefers-reduced-motion: reduce` — движение не запускается, содержимое читаемо сразу.
- Анимируются только `transform` и `opacity`.
- Объём анимаций на мобильных меньше десктопного, разводится `gsap.matchMedia()`,
  а не дублированием кода.

SplitText
- Классы задаются явно через `charsClass` / `wordsClass` / `linesClass` с префиксом секции.
- Сгенерированные узлы остаются внутри контейнера секции.
- Сплит по строкам — после `document.fonts.ready` либо с `autoSplit: true`.
- На `<a>` и `<button>` параметр `aria` задаётся явно.
- Слушатели вешаются на сам `<a>`, а не на сгенерированные узлы.
- Заголовочный тег сплит не подменяет.

## 6. Действует во всех сессиях

- Терминология: клиенту видно «Каменный мир» — в текстах, `aria-label`, JSON-LD.
  «StoneWorld» — только домен, имя проекта и внутренняя документация, клиенту не показывается.
  Ошибка тихая: ни консоли, ни визуального дефекта.
- Клиент, позиция, карточка, секция, цех — синонимов не заводить.
- Имена целей аналитики НЕ назначены. `reachGoal` не пишется. Каждая точка, где он
  потребуется по ANL-3, помечается комментарием `/* ANL: имя цели не назначено */`.
  Обработчики дописываются отдельным проходом.
- Кросс-секционных контрактов ровно два, третьего не заводить:
  1) Каталог → Форма, подстановка типа камня, посимвольное совпадение названий;
  2) GlobalHeader → Mobile_menu, предмет контракта — одно имя атрибута
     `data-sw-menu-trigger`; вся логика внутри Mobile_menu, обе секции переживают
     отсутствие второй.
  Второй контракт в PRD 10 и CLAUDE.md раздел 6 пока не внесён — расхождение известное.
- Названия позиций и портфолио — имена файлов без расширения из `/Materials/Catalog`
  и `/Materials/Photo`. Отдельного списка нет. Alt каталога — по шаблону
  `Каменный ковёр {название} - укладка в Сочи и Краснодаре`, вручную не пишется.
- Приоритет решений при переносе: наш код в T123 → готовый T-блок → Zero Block.
  Референс сделан на Тильде: проверить, не покрывается ли задача готовым блоком.
- Проверить код можно только на опубликованной тестовой странице. В цехе — локальный
  HTTP-сервер, через `file://` шрифт не загрузится.

## 7. Самопроверка перед отчётом

Проверять фактически по коду, не по памяти. То, что проверяется только на опубликованной
странице, проверенным не заявлять.

- [ ] Ни один класс не начинается с `t-` / `tn-`, включая классы SplitText
- [ ] Классы SplitText имеют префикс секции, дефолтных имён плагина в DOM нет
- [ ] Глобальных селекторов нет
- [ ] Потомковый `*` встречается только внутри контейнера и только для `box-sizing`
- [ ] `box-sizing` объявлен первой строкой стилей секции
- [ ] Reset, normalize и правила по `body` в коде секции отсутствуют
- [ ] Все стили обёрнуты в контейнерный селектор секции
- [ ] Каждый `var()` имеет фолбэк, значения совпадают с таблицами design_system.md
- [ ] В `@media` — литеральные px, границы 768/769
- [ ] Весь JS в IIFE, глобальных переменных нет
- [ ] Есть проверки `window.gsap` и `window.SplitText`, `registerPlugin` не дублируется
- [ ] Секция не падает при отсутствии соседей и своих узлов
- [ ] `data-sw-scaffold` снят
- [ ] Ассеты — абсолютные URL, путей цеха не осталось
- [ ] `alt` заполнен, `loading="lazy"` проставлен кроме первого экрана
- [ ] Иерархия заголовков не нарушена, уровни не пропущены
- [ ] Комментарии-маркеры «стиль / поведение / разметка» расставлены
- [ ] Баннер T123 над блоком есть, текст пригоден для копирования в T218

## 8. Форма отчёта

1. Что собрано — по зонам каркаса.
2. Пункты брифа, реализованные не буквально, и почему.
3. ФЛАГИ брифа: какие закрыты, какие остались открытыми.
4. Требует решения пользователя — списком.
5. Чего не хватает для завершения секции (ассеты, тексты, URL, имена целей).
6. Что проверяемо только на опубликованной странице.
